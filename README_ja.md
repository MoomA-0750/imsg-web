# imsg-web

[English](README.md) · **日本語**

自分の Mac が配信する、iMessage のウェブ画面です。

[`imsg`](https://github.com/openclaw/imsg) CLI の上に載せた小さなウェブ UI です。メッセージは
Mac の中にあり、ローカルのサーバーがそれを読み、その サーバーへ自分の
[Tailscale](https://tailscale.com) ネットワーク経由でスマートフォンや別のパソコンから
アクセスします。誰か他人のサーバーに複製されることはなく、公開インターネットに出ることもなく、
メッセージが機械の外へ出るのは**あなたがサインインしたブラウザーへ渡るときだけ**です。

**一人が自分の Mac で使う**ために作られています。アカウントの仕組みも、複数人向けの機能も、
製品らしく振る舞おうという意図もありません。

## できること

**読む**：会話リスト（各行に最新のメッセージ）、最新から開いてスクロールで遡る履歴、Mac の中に
ある画像（本体が未ダウンロードなら Messages のキャッシュしたサムネイル）、アドレス帳の連絡先
写真、その場で再生できる音声メッセージ、リンクカード、返信元のメッセージ、リアクション。

**送る**（**有効にしない限りオフ**）：テキスト、ファイル、ブラウザーで録音した音声。

**できないこと**：返信としての送信、リアクションの送信、既読の変更、入力中の表示、検索。
最初の2つは imsg のブリッジ経路が必要で、それは SIP を無効化して Messages にコードを注入する
ことを求めます。このプロジェクトはそこへは踏み込みません。

## 必要なもの

- **Mac**。Messages にサインインしていて、スリープしない状態であること。すべてそこで動きます。
- **[`imsg-patches/`](imsg-patches/) のパッチを当ててビルドした `imsg`**。本家にない小さな変更が
  4つあります：LaunchAgent 配下での連絡先名の解決、連絡先照会の高速化、リンクプレビュー、
  Messages と一致する未読数。内容とビルド方法はそのディレクトリにあります。
- **Node 24** を、専用の場所に展開したもの。システムの Node でも Homebrew のものでもなく。
  これに Full Disk Access を与えるので、自分で管理している複製であるべきです。
- **Tailscale**、または Mac へ非公開で到達する別の手段。サーバーはループバックにのみ bind し、
  設定された `Origin` 以外を拒否するので、前段に何か置かない限りネットワークからは届きません。

## セットアップ

```sh
git clone https://github.com/MoomA-0750/imsg-web && cd imsg-web
npm ci --ignore-scripts
npm run build

./scripts/install.sh \
  --imsg /path/to/patched/imsg \
  --node /path/to/node-v24.20.0-darwin-arm64 \
  --origin https://your-mac.your-tailnet.ts.net
```

`~/Library/Application Support/imsg-web` の下に専用ディレクトリを作り、ビルドをリリースとして
配置し、**パスワードを尋ね**、LaunchAgent を書いて起動します。`npm run build` のあと同じコマンドを
実行すれば新しいリリースへの入れ替えになります。直前のリリースは戻り先として残り、それより古い
ものは自動的に片付きます。

**代行できないことが2つ**あり、最後に案内します：

- インストールした Node バイナリへの **Full Disk Access**（システム設定 → プライバシーとセキュリティ）。
  macOS が `chat.db` の読み取りの責任を問うのは、ターミナルではなく**その Node バイナリ**です。
- **ポートを tailnet に載せる**こと：`tailscale serve --bg 8787`。

あとは指定したアドレスを開いてサインインします。送信は `--send dry-run`（検証はするが何も送らない）
または `--send live` を付けてインストールするまでオフのままです。

停止・巻き戻し・エージェントの改名などの詳細は [`docs/operations.md`](docs/operations.md) にあります。

## 安全性の考え方

真面目に考えている脅威は明白なものです。**これはあなたの全メッセージを読むので、到達しにくく、
偶然には決して到達できないべきだ**、ということ。

- **ループバックのみ**。サーバーは `127.0.0.1` に bind します。誰が接続できるかを決めるのは、
  前段に置いたもの（Tailscale Serve、SSH トンネルなど）です。
- **パスワード1つ**。scrypt でハッシュ化し、0700 のディレクトリに保存します。セッションは
  `__Host-` 付きの `Secure` `HttpOnly` `SameSite=Lax` クッキーで、放置1日・通算1週間で失効します。
- 全リクエストでの **`Origin` と `Host` の厳密な照合**、変更操作すべてでの CSRF トークン、
  ログイン試行の回数制限。
- **読み取り経路は読み取りしかできません**。RPC クライアントはメソッド許可リスト
  （`status`・`chats.list`・`messages.history`・`watch.*`）を型の上だけでなく**実行時に**強制します。
  送信は別のクライアント・別のプロセスで、両者は経路を共有しません。
- **Mac の外に何も出ません**。プッシュサービスなし、解析なし、リンクプレビューの取得なし
  （Messages が既に保存しているものを使います）、外向きのリクエストは一切ありません。
  ページの CSP は `'self'` 以外を許しません。
- **識別子は渡りません**。ブラウザーが持つ会話・メッセージの ID は、データベース世代に紐づいた
  HMAC です。パス・電話番号・ファイル名がブラウザーに届くことはありません。`chat.db` が入れ替われば、
  ブラウザーが持つ ID はすべて意味を失います。

とはいえ、これで公開しても安全になるわけではありませんし、そのようには作られていません。

## 画面に書いていないこと

知っておくと良いけれど、毎回説明されると鬱陶しいので UI から外してあることです。

- **添付は1件につき1メッセージ**。imsg は1回の送信で1ファイルしか送れないので、10ファイルは
  10メッセージとして、選んだ順に届きます。本文は最初の1つに付きます。途中で失敗したらそこで止まり、
  どこまで送れたかを伝えます。
- **送信は即時**で、確認はありません。**成功時は何も表示しません** — メッセージが現れて入力欄が
  空になることが確認そのものです。失敗したとき、あるいは imsg が結果を保証できなかったときだけ
  表示が出ます。Ctrl+Enter / ⌘+Enter でも丸いボタンでも送れます。入力欄には送信経路
  （`iMessage` か `SMS`）だけが書かれています。
- **青い吹き出しは iMessage、緑はそれ以外**（SMS、RCS、imsg が報告しなかった経路）。本家と同じ
  区別です。imsg は経路を会話単位で報告するので、ある1通だけ別経路になった会話も1色で表示されます。
- **会話リストの各行は最新のメッセージを表示します**。これはリスト本体とは別に読んでいるので、
  空白のままの行は「まだ読めていない」であって「メッセージが無い」ではありません。
- **表示は自動で更新されます**。15秒ごと、およびタブに戻ったとき。更新ボタンはありません。
  読み取りに失敗したときだけ再試行が出ます。
- **サインアウトはありません**。一人・一アカウントなので、セッションは放置すれば自ら失効し、
  Mac から `auth revoke-all` で全セッションを一度に無効化できます。サインイン画面の
  「パスワードを忘れた場合」に残り2つの管理コマンドがあります。
- **スクロールで両方のリストが伸びます** — 会話は上へ、リストは下へ。要求した件数より少なく
  返ってきた時点で止まります。
- **画像は開きます**。Mac にある画像をクリックすると、縦長でも画面いっぱいに表示されます。
  ホイール・ピンチ・ダブルクリックで**ポインタの位置を基準に**拡大縮小し、画面に入りきらなく
  なったらドラッグで移動できます。Escape・背景のクリック・下へ引くことで閉じます。本体が未
  ダウンロードの画像のサムネイルはそれ以上大きくならないので、クリックすると数秒だけその旨を
  画像の上に表示します。それ以外に区別する表示は出しません — 試すまで見分けはつかないからです。
- **音声メッセージはその場で再生できます**。進み具合を示すバーがあり、押した位置へ移動します。
  Messages はこれを CAF で保存していて Safari 以外では再生できないので、**初回再生時に Mac 側で
  AAC へ変換**して以降は使い回します。元のファイルには手を加えません。
- **録音は押しっぱなしではなくボタン**です。何も書いていないとき、右のボタンがマイクになり、
  送るものができた瞬間に送信ボタンへ変わります。録音したものは他の添付と同じ列に並び
  （聞き直す・捨てる・文章を添える、いずれも可能）、**送信は別の操作**です。ブラウザーは無圧縮の
  PCM しか書けないので、Mac 側で AAC へ変換してから送ります（およそ10分の1の大きさで、相手の
  スマートフォンが受け取り慣れた形式）。5分で自動的に止まります。なお**届くのは音声の添付で、
  Messages アプリが作る波形の吹き出しにはなりません**。あの吹き出しは送信側アプリが立てるフラグに
  よるもので、この経路では立てられません（同一ファイルで検証済み：
  [`docs/real-data-findings.md`](docs/real-data-findings.md)）。
- **返信の引用は、そこへ戻る道です**。押すと返信元のメッセージへ移動して2秒ほどリングが付きます。
  画面が動いたあとに目的の1通を見分ける方法が他にないからです。まだ読み込んでいない古い
  メッセージなら、会話の残りを一度だけ（上限1000件まで）取得してから移動します。それより前なら、
  取り繕わずにその旨を表示します。
- **通知は求めるまでオフ**です。「メッセージ」の横のベルで有効になり、そのとき初めてブラウザーに
  許可を求めます。有効化した時点で既にあったものは通知しません。自分が別の端末から送ったものも、
  いま開いている会話に届いたものも通知しません。通知はあなたのブラウザーが描くもので、
  **プッシュサービスへの登録も外部への送信もありません**。有効なあいだ、隠れたタブは1分に1回だけ
  会話リストを読みます（無効なら完全に停止します）。iOS の Safari は**ホーム画面に追加した
  ページ**でないと通知を表示しません。
- **時刻は全てのメッセージには付きません**。日付の変わり目と、1時間以上空いて再開した箇所に
  区切り線が入ります。会話を左へドラッグしているあいだだけ、各メッセージの時刻が横に現れます。
  時刻はどちらの状態でもページの中にあるので、スクリーンリーダーはドラッグなしで読み上げられます。

画面は日本語です。文言以外に言語固有のものはありません。

## 開発

専用の Node **24.20.0** を `PATH` の先頭に置いて（システムの Node は置き換えないこと）：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
npm run test:browser     # 合成の HTTPS、Chromium
```

テストは合成データのみを使い、実際の `imsg` を起動することはありません。**このリポジトリには、
実在の会話に由来するフィクスチャは1つもありません。**

`npm run doctor` は本家の `imsg status` を呼び、Messages.app を起動・修復することがあります。
無害な確認ではありません。
